# v1.1 閱讀體驗與實測

## 用五分鐘讀一篇

1. 在首頁掃過五篇的分類、切入點與值得讀的原因。挑一篇展開一分鐘速讀，看看它用什麼基準、增加什麼成本。
2. 點「開始一起讀」，從帶讀的切入點往下看核心機制。在有圖表的段落點圖卡，對照右欄高亮的原圖與圖說。窄版可以來回切換。
3. 點一個建議追問，等第一段帶引文的回答顯示。點「看同版段落」，核對它引用的確實是眼前的結果。
4. 問一個原文沒有量測的條件。可以把缺文回答轉存待查、標記原文，或將有用的回答濃縮成理解草稿。重開同一個庫，從保存的地方繼續。
5. 展開舊知關聯，試著從理由判斷兩篇共同處理哪個問題，再跳到舊文章、教材或過去留下的問題。

## 來自公開來源的實例

同一套生成流程讀過下列五篇。資料先從摘要進入選題，取得同版全文後重算 L1／L2。這些數字各自對應文中的特定設定。

| 文章 | 全文速讀可以核對的結果 |
| --- | --- |
| AutoOntologyBench | Direct 模式的 Repair 平均成功率為 56.0%，Organization 為 21.3%。[論文](https://arxiv.org/html/2611.27734v1) |
| StereoVLM | OOD 測試上，雙目視差監督的 δ1 為 74.92%，比直接雙目深度監督的 45.89% 高 29.03 個百分點。[論文](https://arxiv.org/html/2611.27915v1) |
| QuantStream3D | 在 NeuralRGBD，InfiniteVGGT 與 FrameVGGT 使用該方法後的 completeness error，比各自只做剪枝低 15.7%。[論文](https://arxiv.org/html/2611.27901v1) |
| EvoTER | 空技能庫的首輪到第四輪，Overall SR 從 53.60% 升至 80.40%。[論文](https://arxiv.org/html/2611.27797v1) |
| Multilingual ABSA | 一個英文餐廳子集上，單次提示每筆生成 371.7 個字詞，逐步精煉為 885.1 個，F1 未勝過單次提示。[論文](https://arxiv.org/html/2611.27807v1) |

另以相同流程讀取 vLLM 的公開發布說明，速讀指出 Step5 在 GB200 上最高 1.95× 的解碼速度，並連回原段。[vLLM v0.34.0](https://github.com/vllm-project/vllm/releases/tag/v0.34.0)

## 真實模型追問

實測使用已載入的 `gemma4:26b`。StereoVLM 與 QuantStream3D 的四段式帶讀分別在 3.615 與 3.552 秒完成。兩篇各從瀏覽器送出三題，包括機制、比較，以及原文缺少數據的邊界。下表單位為秒。

| 六輪追問 | 最短 | 最長 |
| --- | ---: | ---: |
| 模型首字 | 0.563 | 0.886 |
| 首段通過引文校驗、可顯示 | 0.873 | 1.486 |
| 回答完成 | 1.272 | 2.126 |

對兩篇各問一次文中未測的耗電量，模型兩次都回答「原文未交代」。兩份導讀與六輪追問共送出 30 筆引文，逐筆重算後均對應同一版本的原句、錨點與出版者連結。引文可回溯；讀者仍可自行對照，判斷回答的解讀是否成立。模型載入時間、硬體和輸出長度都會影響實際等候時間。

另外使用受控服務驗故障路徑。完全沒有首字時於 15.039 秒中止，已送出有效段落但回答未完成時於 45.021 秒中止。含無效引文的案例在顯示回答前即被攔截。
